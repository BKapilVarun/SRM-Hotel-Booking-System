Sender Email (SMTP) Configuration

How to send real emails to customer inboxes:
1. Enter your Sender Email (e.g. your Gmail).
2. For Gmail: You must create a 16-letter App Password (go to Google Account → Security → 2-Step Verification → App Passwords → create one for "Mail"). Enter that 16-letter password below.
3. Click "Save Configuration" and then test with "Send Test Email".

Mobile SMS Provider Configuration

To deliver real cellular SMS to customer phones, configure Fast2SMS (India/Global) or Twilio. If left blank, SMS alerts will be recorded in the local outbox log.

Live Cloud Storage with Supabase (PostgreSQL):
1. Create a free project at supabase.com.
2. Go to SQL Editor → run the provided supabase_schema.sql script from your project.
3. Go to Project Settings → Data API (or API), copy your Project URL and Anon API Key, then paste them below.
4. All reservations, dining orders, and reviews will automatically be saved online in Supabase!
